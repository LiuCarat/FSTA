# ADHD200 数据集

本目录包含当前工作区中使用的 ADHD200 数据集本地版本，以及经过整理的 AAL 脑区时间序列数据。本文档描述的是仓库中的数据快照，统计日期为 **2026-08-31**，不代表 ADHD200 官方发布包的完整内容。

## 数据内容

- `adhd200_preprocessed_phenotypics.tsv`：与项目数据对应的统一表型文件。
- `AAL_TCs_filtfix/`：按站点和被试组织的 AAL 区域时间序列。
- `AAL_TCs_filtfix/README.md`：AAL 时间序列、站点、扫描和性别统计的详细说明。
- `clean_dataset.py`：用于检查、归一化和生成清洗数据视图的脚本。
- `archive/`：原始汇总表型和站点级表型文件，仅用于数据溯源，不直接由 Graph-BEC loader 使用。

## 数据规模

当前本地数据包含：

- **9 个站点**：`KKI`、`NYU`、`NeuroIMAGE`、`OHSU`、`Peking_1`、`Peking_2`、`Peking_3`、`Pittsburgh`、`WashU`。
- **768 个被试目录**。
- **2,396 个 AAL `.1D` 时间序列文件**。
- 每个 `.1D` 文件包含 **116 个原始 AAL 区域**；前两列为文件信息和子砖信息，因此完整文件共有 118 列。
- 单个 run 的时间点数约为 **55–257**，不同站点和不同扫描 run 之间并不一致。
- 项目下游的 Graph-BEC 配置默认从 116 个区域中使用前 **90 个 ROI**。

被试目录名称使用归一化后的数字 ID。例如，文件名中的 `0016058` 对应目录名 `16058`。匹配表型时应去除数字 ID 的前导零，并同时保留站点信息作为唯一标识。

## 性别、年龄和诊断

与本地时间序列匹配的 768 个被试中：

- 年龄范围为 **7.09–21.83 岁**，平均年龄约 **12.03 岁**。
- `Gender=0`：285 人；`Gender=1`：482 人；缺失：1 人。
- 非缺失性别样本中，`Gender=1` 约占 **62.8%**，`Gender=0` 约占 **37.2%**。
- `Peking_2` 和 `Peking_3` 的性别分布明显不平衡；`Peking_3` 的本地样本全部为 `Gender=1`。
- `KKI`、`OHSU` 主要包含儿童样本；`NeuroIMAGE`、`Pittsburgh` 和部分 `WashU` 样本的年龄范围延伸到青少年或青年阶段。

本项目使用的 `DX` 编码为：

| `DX` | 项目中的含义 |
|---:|---|
| `0` | 对照组 |
| `1`、`2`、`3` | 患者/非对照类别，统一映射为患者标签 |

在本地匹配样本中，诊断分布为：`DX=0` 488 人、`DX=1` 159 人、`DX=2` 11 人、`DX=3` 110 人。由于各站点的诊断比例不同，跨站点建模时应考虑站点效应和类别不平衡。

## AAL 时间序列格式

典型文件名为：

```text
sfnwmrda0010001_session_1_rest_1_aal_TCs.1D
```

文件名通常包含：

- 预处理文件前缀：`sfnwmrda` 或 `snwmrda`；
- 被试 ID；
- `session_N`：扫描 session 编号；
- `rest_N`：静息态 run 编号；
- `_aal_TCs.1D`：AAL 区域时间序列文件。

`.1D` 文件第一行为表头。后续每一行对应一个时间点，每一列对应一个 AAL 区域的平均信号值。Graph-BEC loader 会优先选择 `sfnwmrda*` 文件；一个被试存在多个首选 run 时，会按文件名排序后读取并拼接。

## 表型字段与缺失值

常见表型字段包括：

- `ScanDir ID` / `ScanDirID`：被试 ID；`WashU` 使用无空格列名。
- `Site`：站点编码。
- `Gender`：性别编码。
- `Age`：年龄，通常以岁为单位。
- `Handedness`：利手指标。
- `DX`：诊断类别。
- `Secondary Dx`：继发诊断或共病信息。
- `ADHD Index`、`Inattentive`、`Hyper/Impulsive`：ADHD 相关量表分数。
- `Full4 IQ` 等：IQ 相关指标。
- `QC_*`：静息态或结构像质量控制字段。

缺失值形式不统一，常见值包括空字符串、`N/A` 和 `-999`。建模前应将这些值显式转换为缺失值，不能直接当作正常的连续数值。

## 使用注意事项

1. **按被试统计样本量**：同一被试可能有多个 run，并且可能同时存在 `sfnwmrda` 和 `snwmrda` 两套文件。
2. **归一化被试 ID**：匹配表型时去除数字 ID 的前导零，例如 `0010001` 归一化为 `10001`。
3. **处理多个 run**：可以固定选择一个 run、拼接多个 run，或将 run 作为层级因素；不同策略会改变有效时间点数。
4. **控制站点效应**：站点在年龄、性别、诊断比例、扫描时长和 session 数方面差异明显，建议使用站点协变量、分层划分或留一站点验证。
5. **检查序列长度**：最短 run 只有 55 个时间点；使用固定窗口算法前应检查序列长度是否满足窗口要求。
6. **检查元数据匹配**：`NYU` 表型中有 6 条记录、`WashU` 表型中有 2 条记录没有对应本地时间序列，因此本地可直接匹配的样本数为 768。

## 数据清洗

新增或替换数据后，可以运行：

```bash
python dataset/ADHD200/clean_dataset.py
```

清洗脚本会生成 `cleaned/` 数据视图，并执行以下检查：

- 归一化被试 ID；
- 匹配表型和 AAL 时间序列；
- 检查 ROI 数量和数据形状；
- 检查非有限值；
- 生成清洗摘要和缺失样本清单。

运行 Graph-BEC 前，建议先检查清洗结果，再确认实验配置中的 ROI 数量、run 选择、窗口长度和缺失值处理方式。
