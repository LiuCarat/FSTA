
## 18. Weak QC-Compatible Graph 扩展

当前代码中的 QC 不再被当作“参考 BEC 可靠性分数”，也不再单独构建 QC graph。最终采用的是 **Weak QC-Compatible Graph**：

```text
Phenotype/Fusion Graph
→ 原始 top-k 邻居
→ QC compatibility 只调节已有邻居权重
→ QC-aware Neighbor BEC
→ 原有 PGR-BEC gate
```

### 18.1 QC 的定位

患者图和 QC 分别承担不同作用：

```text
Phenotype/Fusion similarity：决定谁是相关邻居
QC compatibility：决定已有邻居之间的质量差异是否适合传播信息
PGR-BEC gate：决定每条 BEC 边最终修正多少
```

QC 不参与全体受试者的原始距离计算，不单独生成第三张 QC 图，也不改变原始 top-k 邻居集合。

### 18.2 只调整已有 top-k 权重

先由原来的 phenotype 或 fusion graph 得到基础权重：

\[
W_{ij}^{base}
\]

对每个查询受试者 `i` 和参考受试者 `j`，计算 QC 标准化特征之间的平均绝对差异：

\[
d_{ij}^{QC}
=\frac{1}{M}\sum_{m=1}^{M}|z_{im}^{QC}-z_{jm}^{QC}|
\]

再计算弱兼容性系数：

\[
C_{ij}^{QC}
=c_{min}+(1-c_{min})\exp(-\lambda_q d_{ij}^{QC})
\]

最终只在原来非零的 top-k 边上调整：

\[
W_{ij}^{final}
=Normalize(W_{ij}^{base}C_{ij}^{QC})
\]

由于 QC compatibility 直接乘在 `W_{ij}^{base}` 上，基础图中的零权重仍然保持为零。因此 QC 不能引入新的邻居，只能改变已有邻居的相对贡献。

### 18.3 QC-aware Neighbor BEC

邻居参考矩阵改为：

\[
N_i^{QC}
=\sum_jW_{ij}^{final}A_j
\]

其中 `A_j` 仍然是参考受试者的 Original BEC。之后完全复用原有 PGR-BEC：

```text
[A_i, N_i^QC, |N_i^QC - A_i|]
→ PGRBECStatic
→ Refined BEC
```

原有的以下内容不变：

```text
gate_max = 0.5
anchor loss
gate sparsity loss
variance retention loss
Directed BrainNetCNN
```

同时已经删除：

```text
source reliability: W_ij × q_j
query QC → gate 放大
独立 QC graph
```

这样可以避免因为 ASD 的 QC 分布与 TC 不平衡，而系统性降低 ASD 参考 BEC 的传播权重。

### 18.4 QC 字段和 fold-safe 处理

默认 QC 字段为：

```text
func_mean_fd
func_dvars
func_quality
```

每个交叉验证 fold 中：

```text
只使用训练折拟合 log-IQR 标准化参数
→ 对训练/验证/测试折统一变换
→ 计算查询者与参考者之间的 QC 差异
```

默认参数为：

```text
qc-lambda = 0.5
qc-compatibility-min = 0.5
```

`qc-compatibility-min` 防止 QC 对已有图权重产生过强抑制；当两个受试者 QC 差异较大时，兼容性系数最低仍为该值。

### 18.5 运行方式

运行原始 fusion-PGR：

```bash
python Graph_BEC/FSTA_Graph_BEC.py \\
  --input-mode bec \\
  --graph-mode fusion \\
  --qc-mode none \\
  --seed 42
```

运行 QC-compatible fusion-PGR：

```bash
python Graph_BEC/FSTA_Graph_BEC.py \\
  --input-mode bec \\
  --graph-mode fusion \\
  --qc-mode compatibility \\
  --qc-lambda 0.5 \\
  --qc-compatibility-min 0.5 \\
  --seed 42
```

主程序会并行打印和保存：

```text
original
fusion_refined
qc_fusion_refined
```

建议重点比较：

```text
AUC_qc_fusion_refined - AUC_fusion_refined
F1_qc_fusion_refined - F1_fusion_refined
Recall_qc_fusion_refined - Recall_fusion_refined
SPE_qc_fusion_refined - SPE_fusion_refined
```

此外建议审计：

```text
QC 前后 top-k 邻居集合是否保持一致
QC 前后同诊断邻居比例是否异常升高
QC 前后站点邻居比例是否异常升高
```
