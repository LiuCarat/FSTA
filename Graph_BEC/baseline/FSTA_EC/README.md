# FSTA-EC Baseline

This directory contains the FSTA effective-connectivity baseline: the FSTA
network components, its unsupervised training loop, and subject-level BEC
extraction. It is separated from Graph-BEC-specific modules so it is not
mistaken for a Graph-BEC architectural contribution.

`FSTA_EC` is used as the directory name because Python package names cannot
contain the hyphen used in the display name **FSTA-EC**.
